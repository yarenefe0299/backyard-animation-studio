# Look-development reference

Use the accompanying twelve-panel reference board as the visual comparison, not
as a texture, flattened backdrop, or generated frame. Preserve the warm cream
plaster, oak trim, softly lit gray masonry, earth layers and pale blue mechanical
overlays. Keep the silver hatchback, house, chamber and mechanisms persistent.

The opening tells a complete small event before explaining it: a real 3D car
approaches from away, rolls onto the driveway, stops, then lowers as the chamber
is revealed. Tire rotation must follow traveled distance and stop before descent.
Then explain the engineering through the twelve declared actions, showing each
problem and its corresponding solution with close-ups that preserve geography.
Use clean portrait framing, soft contact shadows, rounded manufactured edges,
precise moving connections, and bold white outlined captions in postproduction.

This is a fictional engineering explanation, not a vehicle-lift construction
specification. The runtime inventories these references for provenance; it does
not infer new 3D geometry from an image. A new visual subject needs an appropriate
modeled template before its script can render automatically.
